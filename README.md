# Longbox

A free personal Magic: The Gathering collection tracker. It runs entirely in the browser, with no account or server.

- Add cards by camera, name, set code and number, pasted list, or CSV import
- Browse, search, sort and filter with card images
- See your collection's value in CAD or USD, updated daily

Your collection is stored in your browser only. Use the Backup tab to save a copy or move it to another device.

Card data, prices and images come from [Scryfall](https://scryfall.com). Exchange rates come from the Bank of Canada, with Frankfurter as a fallback. Camera card reading uses [Tesseract.js](https://github.com/naptha/tesseract.js).

This is a fan project, not affiliated with Scryfall or Wizards of the Coast. Magic: The Gathering is a trademark of Wizards of the Coast.

## Hosting

Serve this folder from any static HTTPS host, such as GitHub Pages. There is no build step.
